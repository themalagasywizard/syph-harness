---
name: plan-and-verify
description: Use for multi-step work (code changes, data processing, research) where mistakes are costly.
---
1. Write a short plan: the steps and how you will check each one.
2. Do the steps, using tools to inspect real state rather than assuming it.
3. After each step that changes something, verify it (re-read the file, run the test, check the output).
4. Finish with what you did, what you checked, and anything left unverified.
